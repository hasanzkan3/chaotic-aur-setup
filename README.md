## English

This is the english section of the README.

**INSTALLATION**

1. Clone the repository and navigate into the directory

```bash
git clone https://github.com/hasanzkan3/chaotic-aur-setup.git
cd chaotic-aur-setup
```

2. Make the script executable

```bash
chmod +x chaotic-aur-setup-english.sh
```

3. Run the script

```bash
sudo ./chaotic-aur-setup-english.sh
```

**As root User:**

```bash
./chaotic-aur-setup-english.sh
```

**or install raw file with wget command**

```bash
wget -c https://raw.githubusercontent.com/hasanzkan3/chaotic-aur-setup/refs/heads/main/chaotic-aur-setup-english.sh
```

```bash
chmod +x chaotic-aur-setup-english.sh
```

```bash
sudo ./chaotic-aur-setup-english.sh
```
